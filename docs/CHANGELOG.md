# سجل التغييرات

يتبع هذا السجل Semantic Versioning لقاعدة المعرفة والمنصة معًا. التغيير الجوهري في أي حد أو حالة تنظيمية أو منطق محرك يستلزم رفع رقم الإصدار.

---

## [المنصة 0.2.0] — 2026-11-28 · قاعدة المعرفة 1.0.0 (دون تغيير)

### أُضيف
- مسار «صوّر بدل أن تكتب» للغذاء والتجميل:
  - كاميرا خلفية/أمامية، تبديل، فلاش عند الدعم، إطار توجيه، وإغلاق يوقف المسارات.
  - صور متعددة مع أدوار قابلة للتعديل (جدول، مكونات، وجه أمامي، حصة).
  - معالجة محلية: EXIF، تصغير، قصّ منطقة النص، deskew، رمادي، تقليل ضوضاء، تباين، unsharp، مع الاحتفاظ بالأصل.
  - OCR عربي/إنجليزي عبر Tesseract.js في Web Worker، ونمط `SPARSE_TEXT` للجداول.
  - محلّل قيم غذائية يتعامل مع أعمدة متعددة، kcal/kJ، g/mg/ml، أرقام هندية، فواصل عشرية، وكلمات ملتصقة.
  - محلّل مكونات يحفظ الترتيب والأقواس وأرقام E، ويبقي المجهول.
  - شاشة مراجعة إلزامية: الصور، النص الخام، الثقة، مصدر كل قيمة، الحقول التي تحتاج مراجعة، تعديل/إضافة/حذف.
- مسح باركود محلي عبر ZXing-WASM:
  - EAN-13، EAN-8، UPC-A، UPC-E، GTIN-14.
  - تحقق مستقل من الطول ورقم التحقق، وحفظ الأصفار البادئة.
  - منع القراءة المكررة، وإيقاف الكاميرا بعد النجاح، وقراءة صورة محفوظة، وإدخال يدوي.
- فصل التعريف عن البحث: ذاكرة الجهاز أولًا، ثم Open Food Facts/Open Beauty Facts اختياريًا (v3 ثم v2)، بحقول خام فقط ودون أي درجة خارجية.
- إعداد تعطيل البحث الخارجي، وتخزينه محليًا.
- Service Worker مخصص مع تخزين مسبق للهيكل والخطوط، وتخزين أصول OCR/WASM عند أول استخدام.
- `scripts/copy-vendor-assets.mjs` لنسخ 7 أصول (16.6 ميغابايت) قبل dev/build.
- 22 اختبارًا جديدًا للتصوير والباركود وأخطاء الكاميرا (الإجمالي 85).
- وثيقة [IMAGING.md](IMAGING.md) وتحديث وثائق البنية والاختبار والمصادر والحدود.

### قرارات
- لا رفع للصور، ولا حفظ دائم لها دون إجراء صريح.
- لا تقييم قبل تأكيد المستخدم؛ التأكيد يملأ النموذج فقط، والتقييم زر منفصل.
- Canvas بدل OpenCV؛ لا تُشحن حزمة رؤية كاملة.
- عدم استخدام `vite-plugin-pwa` بسبب تعارض الأقران مع Vite 8؛ قالب Service Worker مخصص يُصدر كأصل حزمة.
- اعتبار البحث الخارجي اختياريًا ومعطّلًا قابلًا، مع بقاء التعريف والتحقق والإدخال اليدوي.
- عدم استنتاج التركيز من ترتيب INCI أو القيم الغائبة من الصورة.

### أُصلح
- دمج الكلمة بقيمتها (`Salt0.8g`، `Per100g`) كان يمنع قراءة الملح والأساس.
- صفوف الجدول كانت تتسرب إلى قائمة المكونات عند استخدام صورة واحدة للجدول والمكونات.
- فشل بناء Service Worker عندما كان يُقرأ من `dist` قبل نسخ `public`.
- خطأ CSS في كتلة الطباعة بعد إضافة أنماط التصوير.

### حدود معروفة
- لا توجد اختبارات آلية على صور حقيقية أو قياس دقة OCR/الجدول/الهوية؛ البروتوكول يدوي.
- لا يمكن التحقق من الكاميرا والفلاش والتبديل دون جهاز فعلي.
- الجداول المتعددة الأعمدة والصور السيئة قد تُقرأ خطأً؛ المراجعة إلزامية.
- لا يُقرأ QR أو Data Matrix في مسار الباركود.
- أصول OCR/WASM لا تعمل دون اتصال قبل تنزيلها مرة واحدة.

## [1.0.0] — 2026-11-27

### أُضيف
- منصة ويب عربية RTL كاملة مبنية بـ React 19 وTypeScript وVite.
- محرك غذائي يحسب **FSA NPM 2004/2005** وفق توجيه يناير 2011:
  - عتبات A وC الرسمية.
  - قاعدة استبعاد البروتين عند A ≥ 11 وFVN < 5.
  - عتبة الغذاء الصلب (≥4) والمشروب (≥1).
  - تحويل kcal→kJ والملح→صوديوم.
  - رفض إصدار النتيجة عند نقص الحقول.
- محرك تجميلي متعدد المحاور مبني على اللائحة (EC) 1223/2009:
  - الملاحق II وIII وV وVI.
  - فحص الحدود حسب فئة المنتج وطريقة الاستخدام.
  - «التحقق غير ممكن» عند غياب التركيز.
  - لا درجة مركبة.
- قاعدة معرفة مستقلة:
  - 21 إضافة غذائية.
  - 50 مكوّنًا تجميليًا.
  - 56 مرجعًا تنظيميًا وعلميًا.
- صفحات: الرئيسية، الغذاء، التجميل، التقرير، قاعدة المعرفة، المنهجية، المصادر، عن المنصة، سجل التغييرات، 404.
- استيراد اختياري بالباركود من Open Food Facts / Open Beauty Facts (حقول خام فقط).
- سجل محلي لآخر 24 تحليلًا ولقطات نتائج، مع إمكانية إعادة الفتح والمسح.
- طباعة/PDF للتقرير.
- تصميم متجاوب مع خطوط Thmanyah المحلية، ووضع طباعة، ودعم تقليل الحركة.
- 63 اختبارًا تغطي:
  - أمثلة FSA الرسمية الستة.
  - عتبات النقاط والتحويلات.
  - مطابقة الإضافات والحظر.
  - حدود التجميل والوسم والجهل.
  - التطبيع العربي وتقسيم المكونات.
  - سلامة قاعدة المعرفة.
- سكربت تحقق `npm run validate`.
- وثائق: README وARCHITECTURE وSCIENTIFIC-METHODOLOGY وDATA-SOURCES وDATABASE-SCHEMA وCONTRIBUTING وCHANGELOG وTESTING وLIMITATIONS.
- سير عمل GitHub Actions للنشر على GitHub Pages.

### قرارات
- استخدام `HashRouter` و`base: './'` لضمان العمل على GitHub Pages.
- عدم استخدام أي درجة تجميلية مركبة، ومنعها على مستوى النوع (`CosmeticsEvaluationResult` لا يحتوي `score`).
- اعتبار الماء/Water/Aqua مكوّنًا أساسيًا لا مادة مقيّمة، مع توضيح أن ذلك ليس تقييمًا للتركيبة.
- عدم استيراد Nutri-Score أو NOVA أو Eco-Score أو أي تصنيف خارجي.
- عدم حساب التعرض الفردي أو الجرعة اليومية.

### أُصلح
- لم يعد الماء يظهر كتنبيه «مكوّن غير مدرج» بعد اعتباره مكوّنًا أساسيًا.
- تُحتسب مسببات الحساسية العطرية في محور الوسم حتى عندما يكون التركيز غير معروف.
- تطبيع سياق فئة المنتج وطريقة الاستخدام (`leave-on`/`rinse-off`) قبل مطابقة الحدود التنظيمية.
- دعم الفاصلة العشرية في قوائم المكونات (`Triclosan 0,3%`).
- البحث في قاعدة المعرفة يبدأ من «الكل» ويستخدم التطبيع العربي، لذلك يعمل البحث بأسماء INCI وأرقام E.
- فتح تقرير من السجل لا يمسح السجل عند فشل التحميل.

### حدود معروفة
- القاعدة محدودة النطاق وليست كاملة.
- لا تقييم للملوثات أو بقايا المبيدات أو مواد التغليف.
- لا تحقق من حدود فئات الغذاء في اللائحة 1333/2008 بالكامل.
- البيانات المستوردة من القواعد العامة تحتاج مراجعة يدوية.
- لا مصادقة ولا مزامنة بين الأجهزة.

## سياسة الإصدارات

| نوع التغيير | مثال | الإصدار |
|---|---|---|
| جوهري | إضافة مادة، تغيير حد، تعديل حالة تنظيمية، تغيير منطق محرك | Major أو Minor حسب الأثر |
| وظيفي | صفحة جديدة، حقل جديد، تحسين واجهة | Minor |
| تصحيحي | خطأ إملائي، رابط، تنسيق، تحسين أداء | Patch |
| تحريري | توضيح صياغة لا يغير المعنى | Patch أو بدون إصدار |

كل إصدار يجب أن يحدّث `src/database/meta.json` و`docs/CHANGELOG.md`، وأن يمر بالتحقق والاختبارات.
