# الاختبارات والتحقق — مِعيار

## 1. الأوامر

```bash
npm run validate   # التحقق من قاعدة المعرفة
npm test           # كل اختبارات Vitest (63)
npm run test:watch # وضع المراقبة
npx tsc -b         # فحص TypeScript
npm run build      # بناء الإنتاج
```

## 2. البنية

```
tests/
├── helpers.ts               # makeFoodProduct
├── npm.test.ts              # عتبات FSA NPM والأمثلة الرسمية
├── food-evaluate.test.ts    # مطابقة الإضافات والتنبيهات والتحويلات
├── cosmetics.test.ts        # الحظر والتقييد والوسم والجهل
├── normalize.test.ts        # التطبيع العربي وتقسيم المكونات
└── data-integrity.test.ts   # سلامة قاعدة المعرفة
```

البيئة: `node`، ولا شبكة، ولا اعتماد على الوقت الحقيقي.

## 3. التغطية الحالية (63 اختبارًا)

### 3.1 `npm.test.ts` — 10 اختبارات
- النقطة تُمنح عند التجاوز الصارم فقط (`>` وليس `≥`).
- نطاقات الفواكه والخضروات والمكسرات (40/60/80).
- عتبات الألياف NSP وAOAC المختلفة.
- عتبات البروتين.
- أمثلة FSA الرسمية الستة:
  - فروماچ فواكه = 0.
  - آيس كريم فانيليا = 12 مع استبعاد البروتين.
  - ميلك شيك = 0.
  - شوربة كوب = 5.
  - بار فواكه ومكسرات = 6 مع استبعاد البروتين.
  - مشروب عصير = 2 (عتبة المشروب).
- تحويل kcal→kJ.
- تحويل الملح→صوديوم.
- رفض النتيجة عند نقص حقل مطلوب.

### 3.2 `food-evaluate.test.ts` — 9 اختبارات
- مطابقة E102 بالرقم وبالاسم الإنجليزي.
- عرض ADI دون ادعاء حساب التعرض.
- رصد E171 كمحظور.
- توسيع نطاق E 220–E 228.
- إبقاء المكونات غير المطابقة وعدم اعتبارها آمنة.
- تقرير نقص البيانات ومنع النتيجة.
- ملاحظة تحويل الملح.
- تنبيه نوع الألياف غير المحدد.
- تطبيق عتبة المشروب.

### 3.3 `cosmetics.test.ts` — 19 اختبارًا
- الفورمالديهايد محظور.
- الهيدروكينون محظور خارج أنظمة الأظافر.
- التريكلوسان ضمن 0.3% في صابون اليدين، ويتجاوز عند 0.5%.
- التريكلوسان غير مسموح في كريم الوجه.
- MI مرفوض في المنتجات التي لا تُشطف.
- MI مقبول عند 0.0015% في منتجات تُشطف.
- حمض الساليسيليك: حد 0.5% للوشن الجسم، و3% للشامبو.
- الريتينول يتجاوز حد لوشن الجسم.
- وسم الليمونين: ضمن الحد، متجاوز، وتركيز غير معروف.
- مطابقة Sodium Methylparaben إلى Methylparaben.
- مطابقة خليط MCI/MI.
- المكوّن غير المعروف لا يُعتبر آمنًا.
- الماء لا يُحسب مكوّنًا مجهولًا ولا يظهر في تنبيهات التغطية.
- وسم مسببات الحساسية العطرية يُحتسب في محور الوسم حتى عند غياب التركيز.
- عدم وجود `score` في النتيجة.
- ثاني أكسيد التيتانيوم: تحقق غير ممكن دون تركيز.

### 3.4 `normalize.test.ts` — 11 اختبارًا
- تطبيع التشكيل والألف والياء والتاء المربوطة والأرقام العربية.
- تطبيع الحالة والترقيم الإنجليزي.
- توحيد أرقام E وتوسيع النطاقات.
- تطبيع أرقام E داخل النص.
- تقسيم الفواصل والأسطر والفواصل العربية.
- احترام الأقواس.
- استخراج النسبة النهائية وعدم اختراعها.
- الفاصلة العشرية (`0,3%`).
- مرادفات التجميل.
- إزالة أقواس CI فقط.

### 3.5 `data-integrity.test.ts` — 14 اختبارًا
- تطابق العدادات.
- تفرد المعرّفات.
- وجود كل مرجع.
- روابط http(s) وتواريخ اطلاع صحيحة.
- عدم وجود نصوص مؤقتة.
- وجود مرجع لكل تقييم علمي.
- E171 محظور.
- الفورمالديهايد في الملحق II.
- التريكلوسان في الملحق V بحد 0.3%.
- مسببات الحساسية التسعة بحدود 0.001% و0.01%.
- رقم وثيقة FSA.

## 4. التحقق من قاعدة المعرفة

`npm run validate` يفحص:
1. عدادات `meta.json`.
2. تفرد المعرّفات.
3. وجود كل `reference_id`.
4. صحة الحالات التنظيمية.
5. صحة مستويات الثقة وحالة التحقق.
6. قيم الحدود غير السالبة أو `null`.
7. الحقول النصية الإلزامية.
8. صحة روابط المراجع.
9. صحة أرقام E.
10. وجود `inci_name`.

المخرجات المتوقعة:

```
✓ التحقق من قاعدة المعرفة ناجح
  المراجع: 56
  الإضافات الغذائية: 21
  المكونات التجميلية: 50
  النسخة: 1.0.0
```

## 5. التحقق اليدوي قبل النشر

### 5.1 الغذاء
- [ ] افتح `/food` وتأكد أن التسميات وRTL سليمة.
- [ ] اضغط «تعبئة مثال توضيحي» ثم «احسب التقرير».
- [ ] تحقق من ظهور النتيجة 0 وتصنيف «غير مصنّف أقل صحة».
- [ ] أدخل منتجًا ناقص الحقول وتأكد من ظهور قائمة الناقص ومنع النتيجة.
- [ ] أدخل `E102` وتأكد من بطاقة الإضافة وADI.
- [ ] أدخل `E171` وتأكد من تنبيه الحظر.
- [ ] جرّب مشروبًا بنتيجة ≥1 وتأكد من التصنيف.
- [ ] جرّب استيراد باركود وهمي وتأكد من رسالة الفشل دون تعطل.

### 5.2 التجميل
- [ ] افتح `/cosmetics` وجرّب المثال (شامبو + MI 0.002%).
- [ ] تحقق من محور «مقيد» ومن عدم وجود درجة.
- [ ] جرّب `Formaldehyde` وتأكد من «محظور».
- [ ] جرّب `Limonene` دون تركيز وتأكد من «وسم إلزامي — تركيز غير معروف».
- [ ] جرّب `Triclosan` في كريم وجه وتأكد من «غير مسموح في هذه الفئة».
- [ ] جرّب مكوّنًا مجهولًا وتأكد من محور «غير معروف».
- [ ] تأكد من أن التركيز لا يُستنتج من الترتيب.

### 5.3 التقرير والسجل

## 6. فجوات الاختبار المعروفة

- لا اختبارات E2E بمتصفح حقيقي (Playwright/Cypress).
- لا اختبارات لقطة بصرية.
- لا اختبارات وصول آلية (axe).
- لا اختبارات لسلوك الشبكة الفعلي في `barcode.ts` (تعتمد على المراجعة اليدوية).
- لا اختبارات أداء أو ميزانية حزمة.
- لا اختبارات لتعدد المتصفحات.
- لا اختبارات لاستيراد ملفات أو تصدير.

هذه الفجوات موثقة، وليست ادعاء تغطية كاملة.

---

## 7. عند فشل اختبار

1. اقرأ الرسالة والملف والسطر.
2. حدد هل الخطأ في المحرك أم في التوقع أم في البيانات.
3. لا تُعدّل التوقع لتجاوز خطأ حقيقي.
4. إذا كان الخطأ في البيانات، صحّح المصدر أولًا.
5. أعد تشغيل المجموعة كاملة، ثم `npm run validate` و`npx tsc -b` و`npm run build`.
